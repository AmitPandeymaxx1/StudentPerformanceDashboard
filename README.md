**Student Performance Analytics Dashboard**
**Overview**
- This project is an interactive dashboard built using R Shiny to analyze student performance.

**Features**
- Student Performance Analysis
- Attendance Filter
- Marks Filter
- Scatter Plot
- Histogram
- Pass/Fail Analysis
- Marks Prediction
**Technologies Used**
- R
- Shiny
- ggplot2
- dplyr
